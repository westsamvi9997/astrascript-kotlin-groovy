## What AstraScript Provides

AstraScript combines a reusable script library with a framework intended for Minecraft, desktop, and web scenarios. Both Kotlin DSL and Groovy DSL workflows are available, allowing teams to choose between different authoring styles while keeping automation and modding work within a consistent project structure.

Its platform-aware transpilation approach helps carry scripts between environments with less manual rework. The collection also includes a bridge for visual scripting, AI-assisted suggestions, context-sensitive documentation, and sandbox execution to support development, experimentation, testing, and ongoing maintenance.
